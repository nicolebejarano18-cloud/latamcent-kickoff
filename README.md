# LatamCent Kickoff Call Template

Interactive 10-section kickoff call template. Fill out during the call, click **Done** on section 10 to export a formatted PDF.

## Sections
1. Call details
2. Pre-call prep checklist
3. Current state discovery
4. Defining success
5. Role & scope specifics
6. Compensation & logistics
7. Interview process design
8. Ideal candidate profile (ICP)
9. Sample profile review
10. Cadence & close

## Deploy
Deployed via Vercel. Any push to `main` triggers a new deployment.
